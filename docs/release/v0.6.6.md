# v0.6.6 Ibis — 当前功能的首次 ZIP 交付（Beta）

发布日期：2026-10-11。版本由作者明确指定为 **v0.6.6**，仍处于 Beta；发布不代表 N1、N5 或全部 N 阶段已完成。

## 下载与运行

从 [GitHub Release](https://github.com/VUA-Project/VUA/releases/tag/v0.6.6) 下载 **VUA-0.6.6-windows-x64.zip**。完整解压后运行 **VUA.exe**，保留 resources、locales 和其它配套文件。运行不需要源码、Node、pnpm 或 Rust。

本包面向 **Windows x64**，尚未签名，Windows 可能显示未知发布者提示。Steam、SteamVR、VRChat、PICO Connect、Unity 与 VRCFaceTracking 由其官方应用或安装器提供，不包含在 VUA 的 ZIP 内。

更新时先退出 VUA，再把新版完整解压到另一个目录。应用数据保存在 `%APPDATA%\VUA`，与程序目录分离；试用 Beta 前建议备份。删除解压目录可以移除程序，数据目录由用户另行决定是否保留。

## 本次交付

- **情景首页与引导**：游玩、工具、改模采用统一的卡片详情交互；首次启动根据支持的系统语言选择界面语言，提供欢迎导览和按目标、设备展开的入门引导。保留矩阵背景、侧栏和小窗口毛玻璃、资源节约模式。
- **游玩准备**：桌面与 PICO 情景提供前提检测、计划、官方软件获取交接、引导和启动/关闭操作；只尝试关闭该情景本次启动的软件，保留已运行的共享软件。Quest 等尚未交付的选项明确标记开发中。
- **游戏内助手**：跟随 VRChat 窗口显示和隐藏，背景透明度与文字分离，记住手动拖动后的相对位置。手动隐藏和不抢焦点的恢复逻辑保留。
- **网络参考**：提供美西、美东、日本、欧洲四处的地理参考延迟；使用连接预热后的多次响应中位数。它是公开参考目标的 HTTP 时延，**不是实际 VRChat/Photon 房间 Ping**。Steam/GitHub 等网站检查位于展开面板。
- **AMF＋BDL 隔离**：AMF 随包提供，新用户默认启用，可在改模或设置 → 模块关闭；旧设置与本地数据保留。AMF 未启用或启动失败时，宿主游玩和设置仍可使用。BOOTH 同步按登录状态交接，Unity 检测包含 C1，素材管理保留已审查的获取与本地整理实现。
- **素材浏览与百科**：AMF 的内嵌浏览器保留顶栏和侧栏，支持多标签、各标签独立历史及页面状态在本次运行中的保留；提供 BOOTH 与选定素材网站快捷方式。帮助内提供入门引导、知识百科、硬件介绍、游戏内助手和官方 VRChat Wiki。
- **VRCFaceTracking 连接**：提供检测、Steam 官方安装入口、启动/本次所有权关闭、设备选择和对应模块/OSC 设置指导。设备列表不等于已检测到全部硬件，模块安装和校准仍在上游应用完成。
- **外观与资源信息**：替换像素机器人，使用 VUA 品牌标志与功能域颜色切换；资源面板增加 CPU/GPU 使用率，并区分缺失数据和共享内存显卡。

## 检查与验收口径

发布提交须通过 Rust workspace 测试/Clippy、TypeScript 检查与单测、生产构建、边界、四语言一致性、对比度、开发数据泄漏和 schema vectors 检查。原生 UI 冒烟覆盖入门引导、模块开关、帮助导航、浏览器标签、区域参考、托盘、开屏、资源与 VRCFT 控制流程，其中供应商、网络和硬件结果使用标明的合成场景。

最终 ZIP 另行在隔离数据目录测试：中文/空格路径完整解压与启动；不依赖开发工具；实际随包宿主和 AMF Provider 响应；移动程序目录后的数据保留；缺失宿主 Provider 时明确失败。**这不是缺失第三方软件的安装验收，也不是完整 PICO 或 Avatar 制作验收。** 发布资产中的 `release-manifest.json` 记录实际源码提交、包校验值、检查结果和范围，许可清单保存在 ZIP 的 `resources/notices/build/`。

## 尚未完成与已知限制

- 缺失 Steam/PICO 等软件的完整真实安装路径、PICO USB/Wi-Fi 实物游玩、VRCFT 真机追踪与校准仍待验收；已有软件复用或合成检查不能替代这些结果。
- N1、N5 的正式真机/真实素材验收与作者参与的四语言人工 UI 审查仍未完整完成；AMF 的复杂改模、Recipe 共享/复现按 N3/N4 后续推进。
- 部分工具和设备仍是开发中占位；MioVRC 集成不在本次交付范围内。Unity 6 占位不表示已支持该版本的制作流程。
- 参考测速目标、线路与负载会影响结果，不能用参考数值判断实际房间延迟。精准 Photon 测量后续另做。
- 浏览标签状态保留于当前应用运行，退出后不承诺恢复页面或登录态；账号与上传仍按官方界面手动完成。
- 本包为完整 ZIP，**没有 NSIS、运行时镜像下载/复用或 AMF 独立增量更新**；已接受的 Windows 分发计划在本次发布之后实施。未完成的签名申请不写成已签名。
