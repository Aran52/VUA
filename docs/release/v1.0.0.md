The author selected **v1.0.0 Brave New World** as the first stable host release. **AMF 0.3.0
remains Beta**, is included for new installations and updates independently. Brave New World
names Aldous Huxley's novel and the Stellaris achievement for colonizing the first planet.
Stable describes the host lifecycle; the acceptance limits below still apply.

## Installation and upgrade

The prepared Windows x64 installer names are **VUA-1.0.0-windows-x64-setup.exe** (online) and
**VUA-1.0.0-windows-x64-offline.exe** (runtime included). These are expected asset names, not
available downloads in this draft. The [current download page](https://ph-r.com/vua/downloads/)
continues to serve the published release until promotion. No signing or server configuration is
changed by this preparation.

To upgrade from 0.7.0, finish production, exit VUA and run the matching 1.0.0 installer when it
is published. It updates the host and AMF together: AMF 0.3.0 needs host 1.x and is not offered
to a 0.7 host as a standalone module update. Preserving materials, Recipes, settings, history
and saved module choices across that upgrade remains a clean-VM acceptance item.

## Changes since 0.7.0

- The full name is **Virtual Unified Assistant** in the app and installer.
- First use follows the system language and opens a four-part notice. “Got it” starts the
  skippable feature tour; the beginner entry explains one concept at a time, starting with
  VRChat, with links to the matching setup page and encyclopedia.
- AMF opens Warehouse, Recipe, Workshop and Release from a plain station list. The unused
  base map and production animation are removed.
- Library migration has directory choices, loose-file groups, confirmed/unassigned/excluded/
  unreadable areas and a versioned manifest. Opening the planner imports nothing.
- Before assembly, each outfit's plan shows size, triangles, material slots, texture memory,
  PhysBones and parameter bits. These are estimates; compare the built result before relying
  on them.
- Intake recognizes VRCFury components and opens the official-package guide. VRCFury is guide
  delivery, not a bundled package.
- The title bar names the tightest resource. The ineffective “Show completed” setting is gone.
- Grid, Aero, Tenshi and Jirai ship as the four approved styles.
- The merged work also includes independent component updates and recovery, contextual terms,
  turntable/Recipe sharing, local material entry, the Unity license step and MCP access to
  connected Steam tools.
