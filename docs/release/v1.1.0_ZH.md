# v1.1.0 Getting on Track

> 状态：发行准备；尚未声明 1.1.0 已公开发布或完成安装器实机验收
> 更新：2026-11-13
> 语言：awaiting native review（待母语审校）

其他版本：[English](v1.1.0.md) · [日本語](v1.1.0_JA.md) · [한국어](v1.1.0_KO.md)

作者已选择 **v1.1.0 Getting on Track** 作为本体的下一个稳定版，搭档 **AMF 0.4.0 Beta**
（需要本体 `>=1.1.0, <2.0.0`）。Getting on Track 取自《异星工厂》（*Factorio*）造出第一台火车头的里程碑成就。
AMF 继续保持 Beta，新安装默认随包启用，并在本体兼容范围内保持独立更新。稳定版描述本体的生命周期阶段，
下面的验收限制与待测项仍然适用。

## 安装与升级

准备中的 Windows x64 安装包文件名为 **VUA-1.1.0-windows-x64-setup.exe**（在线）和
**VUA-1.1.0-windows-x64-offline.exe**（含运行时）。在正式发布前它们只是预期的产物名称；
当前公开下载仍为 [v1.0.0](https://github.com/VUA-Project/VUA/releases/tag/v1.0.0) 及
[官网镜像](https://ph-r.com/vua/downloads/)标明的已发布版本。安装包尚无 Windows Authenticode
签名，首次运行时系统可能提示未知发布者；发布清单的 Ed25519 签名用于校验更新来源。

从 1.0.0 或 0.7.0 升级时，先完成手头工作并退出 VUA（含右下角托盘图标），待 1.1.0 正式发布后运行新版安装器。
安装器会一并更新本体与 AMF，并复用已校验通过的同版本 Electron 运行时：AMF 0.4.0 调用了 1.1.0 本体新增的改模产线、
本地 SDK 测试、外部工具连接与商品信息补全接口，因此需要本体 `>=1.1.0, <2.0.0`，不会向 1.0.0 本体单独推送模块更新。
原有 `%APPDATA%\VUA` 应用数据保持不变，干净虚拟机上的升级验收仍待完成。

## 相比 1.0.0 的变化

- **原生现代 Windows 安装与卸载界面**：将多步传统 NSIS 向导替换为单卡片 Per-Monitor DPI v2 原生安装/卸载界面，
  自动跟随系统深浅色与 Windows 首选显示语言顺序（`en`、`zh-CN`、`zh-TW`、`ja`、`ko`），支持程序占用或网络失败时原地重试、
  安装完成自动启动，并完整保留 `/S`、`/ISOLATED` 与 `/D=` 自动化参数。
- **启动提速、体积减半与压缩增量更新**：采用轻量静态启动画面、Main 与宿主 Provider 并行初始化、AMF 进程延后拉起、
  `VUA.Runtime.exe` 硬链接复用 Electron 运行时、多线程哈希校验与启动器交接、精简非运行时许可文件，并新增带签名的
  `windows-distribution v0.3` zstd 压缩组件包。安装后磁盘占用由约 875 MiB 降至约 450 MiB。
- **按目标组织的启动页与外部工具连接**：启动页（`scenario-environment v0.2`）围绕 3 个社交平台与 15 项设备/游玩方式（桌面屏幕、SteamVR
  串流、PICO 串流与独立头显商店游玩）组合对应准备步骤；工具连接新增 `external-tool v0.4` Steam 条目与 `installer-tool v0.1`
  官方安装程序引导。
- **Avatar Optimizer、本地 SDK 测试与 Recipe v0.6**：AMF 装配新增可选 `com.anatawa12.avatar-optimizer`
  优化步骤与 NDMF 克隆指标（`amf-production 0.43.0`、`unity-bridge-v5 0.24.0`），补齐带校验草稿预填、旧版迁移的
  Recipe 管理与 `amf-recipe v0.6`（`0.1.0`），并加入本地 Avatar SDK 测试构建与上传资格观察
  （`amf-production-flow v0.1`）。移除工作 Unity 工程后，已完成 Avatar 仍保留预览图。
- **大素材库读取提速、BOOTH 真实购买时间与商品补全**：读缓存与独立读取线程让大素材库在后台扫描期间仍保持约 110 ms
  响应；「最近添加」改为按 BOOTH 订单页的真实购买时间排序，并为已购商品补充有界商品观察信息
  （`catalog-enrichment v0.1`）。
- **签名指南通道、更新安全与五语言细节打磨**：新增带内置兜底与来源监控的 `guide-content v0.1` 签名指南通道；
  妥善处理已撤回或不兼容的组件更新；首次自动更新检查推迟到首次使用须知关闭之后，并明确披露 7 天日志保留与按
  `Asia/Shanghai` 切天的无安装 ID 汇总统计；窗口与安装器显示名称统一简化为 `VUA`；打磨五语言界面文案、百科、最小指南及 Grid、Aero、Tenshi、Jirai 四套主题对比度与布局。
