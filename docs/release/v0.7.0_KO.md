# v0.7.0 Stone Age — 아바타 공방(Beta)

> 이 한국어판은 기계 지원으로 작성했습니다. 원어민 검토를 기다리고 있습니다.

버전은 작성자가 **v0.7.0 Stone Age**로 정했습니다. VUA는 계속 Beta입니다. 이번 버전은 처음으로
실제로 쓸 수 있는 아바타 제작 흐름을 담았습니다. 라이브러리에서 아바타와 의상을 고르면 VUA가 전용
Unity 프로젝트에서 조립하고, 확인을 거쳐 VRChat에 업로드합니다.

다른 언어: [English](v0.7.0.md) · [简体中文](v0.7.0_ZH.md) · [日本語](v0.7.0_JA.md)

## 다운로드와 설치

[GitHub 릴리스](https://github.com/VUA-Project/VUA/releases/tag/v0.7.0) 또는
[공식 다운로드 페이지](https://ph-r.com/vua/downloads/)에서 Windows x64 설치 파일을 고르세요.

- **VUA-0.7.0-windows-x64-setup.exe**: 작은 온라인 설치 파일입니다. VUA와 AMF를 포함하며, 설치할 때
  연결되는 미러에서 맞는 런타임을 받습니다.
- **VUA-0.7.0-windows-x64-offline.exe**: 런타임을 포함한 같은 버전입니다. 오프라인이거나 네트워크가
  불안정한 환경에 맞습니다.

v0.6.7에서 업데이트하려면 작업을 마치고 VUA를 종료한 뒤 0.7.0 설치 파일을 실행하세요. 본체는
0.7.0, AMF 모듈은 **0.2.0**이 됩니다. AMF 0.2.0은 0.7 계열 본체가 필요하므로 v0.6.7의 모듈
업데이트에는 나타나지 않습니다. 프로필, 라이브러리, 프로젝트, 레시피, 계정 정보는 그대로 유지됩니다.
0.7 계열의 이후 AMF 업데이트는 "설정 → 모듈" 또는 "정보"에서 할 수 있습니다.

설치 파일에는 아직 Authenticode 서명이 없습니다. 업데이트 출처는 릴리스 매니페스트의 Ed25519
서명으로 확인합니다. Unity, VRChat SDK, Steam, VRChat과 각 도구는 각자의 공식 배포처에서 받습니다.

## 새로운 기능

### 아바타 제작(AMF)

- **소재 방에서 완성된 아바타까지.** 아바타와 맞는 의상을 고르면 VUA가 제작 라인을 엽니다. 라인마다
  전용 Unity 작업 프로젝트가 있고, 원본 패키지는 건드리지 않습니다.
- **공방.** 라인은 소재, 검사, 계획, 조립, 품질 검사 스테이션을 차례로 거칩니다. VUA는 아바타와
  의상 프리팹을 이유와 함께 추천합니다. 의상은 Modular Avatar로 입히고, 의상마다 메뉴 스위치가
  붙습니다. 미리보기로 정면·측면·후면 결과를 볼 수 있습니다.
- **권한 모드.** "변경 전에 묻기"(기본), "스스로 판단", "모두 맡기기"로 확인 없이 어디까지 진행할지
  정합니다. "모두 맡기기"는 먼저 주의를 보여 줍니다.
- **셰이더와 의존 패키지.** 소재에 필요하면 lilToon, Poiyomi Toon(버전 계열별), UnlitWF를 공식
  피드에서 설치합니다. 직접 받아야 하는 패키지는 공식 페이지를 안내합니다.
- **머티리얼 조정.** 의상의 lilToon 밝기 상한·하한을 아바타에 맞춰, 어느 월드에서든 함께 밝아지고
  어두워지게 합니다.
- **변경과 복원.** 완성된 라인의 의상이나 베이스 아바타 변경, 라인 삭제, Unity 작업 중지와 계속,
  중단된 단계 복원이 가능합니다. 변경마다 복원 지점을 남기고, 실패한 변경은 자동으로 되돌립니다.
- **작업 대기열.** Unity 작업은 보이는 대기열에서 순서를 기다립니다. 최대 3개 라인을 나란히 돌릴 수
  있습니다(공방에서 설정).
- **SDK 단계를 쉬운 말로.** VRChat SDK 자체의 아바타 검사를 실행해 "업로드 전에 고칠 것", 알림,
  참고로 나누고 퍼포먼스 등급을 보여 줍니다. SDK 자동 수정은 릴리스 화면에서 실행할 수 있습니다.
  업로드 뒤에 검사를 다시 읽으므로 SDK 패널에서 고친 내용도 반영됩니다.
- **릴리스 룸.** 60프레임 턴테이블 앨범, 그리고 VUA에서 콘텐츠 권리를 확인한 뒤 열린 Unity Editor의
  SDK를 통한 관리형 업로드. 업로드마다 VRChat 아바타 ID나 SDK가 알려 준 이유를 기록합니다.
- **이용 약관.** 라이브러리의 상품 서랍에서 상품의 VN3 약관을 읽고 용도별로 쓸 수 있는지 보여
  줍니다. 제작자의 특기 사항이 맨 위에 옵니다. 릴리스 룸에서는 고른 용도로 라인의 아바타와 의상을
  함께 확인합니다.
- **레시피.** 완성된 라인을 레시피(소재 내용, 선택, 조정)로 저장하고 다른 라인에 적용할 수 있습니다.
- **Unity와 라이선스.** Unity 작업 전에 Unity Hub를 실행하고, Microsoft Store(MSIX)판 Hub도
  인식합니다. 라이선스 상태와 다음에 할 일을 보여 줍니다.

### 실험적 VRChat 로그인

기본값은 꺼짐이며 "설정 → 실험적 기능"에 있습니다. 먼저 위험을 설명합니다. VRChat 약관은 자격
증명을 본인이 관리하도록 요구하며, 서드파티 로그인은 계정 조치로 이어질 수 있습니다. 동의하면 VUA
안에서 로그인하고 VRChat의 2단계 인증을 거칩니다. 이후 관리형 업로드는 SDK가 로그인된 상태로
시작하고, 릴리스 룸은 업로드한 아바타를 VRChat 아바타 목록과 대조합니다. 세션과 기억한 비밀번호는
Windows 사용자별로 암호화해 저장합니다.

### 도구와 AI 에이전트

- **Steam 도구 6개**가 하나의 연결을 함께 씁니다: VRCFaceTracking, Space Calibrator, OVR Advanced
  Settings, OVR Overlay Translator, OVR Toolkit, OyasumiVR. 검색, 설치 안내, 실행, 상태 확인을
  지원합니다.
- **로컬 MCP 연결.** 외부 AI 에이전트가 VUA의 정보를 읽고 작업을 요청할 수 있으며, 요청은 매번
  VUA에서 직접 승인합니다. 결과는 간결하고, 라인의 전체 정보는 MCP Resource로 읽을 수 있습니다.
  오류에는 다시 시도해도 되는지가 담기고, `vua_status`는 정확한 빌드를 알려 줍니다.

### 그 밖의 개선

- 플레이 네트워크 타일은 지역마다 연결 3개로 측정해 가장 빠른 응답을 씁니다. 여러 번 측정해도
  가장 가까운 지역이 같게 나옵니다.
- 다운로드 중에도 작업 행이 제자리에 있습니다. 제작 기록은 "설정"에 있고, 작업 중에 종료하면 먼저
  묻습니다.

## 확인한 것과 확인을 기다리는 것

작성자 환경에서의 실제 실행(2026-10-16~10-19):

- 의상을 입힌 아바타(Meiyun과 티셔츠·반바지)를 준비·조립했고 lilToon 표시도 정상이었으며, SDK로
  빌드한 뒤 관리형 업로드로 비공개 업로드를 두 번 마쳤습니다.
- 셰이더가 없던 머티리얼에 공식 피드에서 lilToon을 설치했습니다.
- Unity Hub가 꺼진 상태에서 VUA가 실행했고 Unity가 라이선스를 받았습니다.
- 외부 AI 에이전트가 대기열 추가, 취소, 중지와 계속, 소재 변경, 라인 삭제, 업로드를 진행했고,
  작성자가 요청마다 승인했습니다.

작성자 확인 대기: 실제 계정으로 하는 실험적 로그인, Poiyomi Toon, 어두운 월드에서의 밝기 맞춤,
라인 2개 동시 실행, 베이스 아바타 변경, 실제 상품의 VN3 약관, 여러 네트워크에서의 지역 지연.

엔진에는 들어가 있고 공방 화면은 다음 버전에서 제공할 것: 라인의 버전 기록(최근 50개 상태에서
복원), 저장한 의상 위치 조정, 페이스 트래킹 애드온.

이번 버전은 깨끗한 환경, PICO USB/Wi-Fi, 복잡한 소재, 4개 언어 사람 검수를 거친 것이 아닙니다.
지역 지연은 각 지역 참조 지점까지의 HTTP 응답 시간이며 VRChat 룸 Ping이 아닙니다.
