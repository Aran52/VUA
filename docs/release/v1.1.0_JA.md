作者は次の安定版ホストとして **v1.1.0 Getting on Track** を選びました。同梱される
**AMF 0.4.0 Beta**（ホスト要件 `>=1.1.0, <2.0.0`）は引き続き Beta として提供され、互換範囲内で個別に更新されます。
Getting on Track は *Factorio* で最初の機関車を製造する実績名に由来します。安定版はホストのライフサイクルを示し、
以下の未確認事項と制限は引き続き適用されます。

## インストールと更新

準備中の Windows x64 インストーラー名は **VUA-1.1.0-windows-x64-setup.exe**（オンライン）と
**VUA-1.1.0-windows-x64-offline.exe**（ランタイム同梱）です。公開前の予定ファイル名であり、現在の公開版は引き続き
[v1.0.0](https://github.com/VUA-Project/VUA/releases/tag/v1.0.0) と
[公式ミラー](https://ph-r.com/vua/downloads/)で提供されます。Authenticode 未署名のため初回実行時に Windows
が警告を表示する場合がありますが、更新元はリリースマニフェストの Ed25519 署名で検証します。

1.0.0 または 0.7.0 から更新する際は、作業を終えてタスクトレイを含め VUA を終了し、公開後に 1.1.0
インストーラーを実行します。検証済みの一致する Electron ランタイムを再利用しつつ、ホストと AMF を同時に更新します。
AMF 0.4.0 は 1.1.0 ホストで拡張された制作ライン、ローカル SDK テスト、外部ツール連携、商品情報補完のインターフェースを
利用するためホスト `>=1.1.0, <2.0.0` が必要であり、1.0.0 ホストに単体更新としては配信されません。
`%APPDATA%\VUA` のデータは保持されます（クリーン VM での更新確認は未完了）。

## 1.0.0 からの変更

- **ネイティブの新しい Windows インストーラー・アンインストーラー**：従来の複数ページの NSIS ウィザードを、
  Per-Monitor DPI v2 対応の単一カード型ネイティブ UI に置き換えました。システムのダーク／ライト設定と Windows
  の優先表示言語順（`en`、`zh-CN`、`zh-TW`、`ja`、`ko`）に従い、起動中ロックや通信エラー時のその場での再試行、
  完了後の自動起動に対応し、`/S`・`/ISOLATED`・`/D=` オプションも維持します。
- **起動の高速化、導入サイズの半減、圧縮更新**：軽量な静的スプラッシュ画面、Main とホスト Provider の並列起動、
  初期描画後の AMF 遅延起動、`VUA.Runtime.exe` のハードリンク共有、並列ハッシュ検証とランチャーからの引き継ぎ、
  同梱ライセンス通知の整理、署名付き `windows-distribution v0.3` zstd 圧縮パックにより、導入後のディスク使用量を
  約 875 MiB から約 450 MiB へ削減し起動時間を短縮しました。
- **目的別の起動画面と外部ツール連携**：起動画面（`scenario-environment v0.2`）で遊び方（デスクトップ画面、
  SteamVR PC VR、PICO ストリーミング）を選ぶと手順を組み立てて案内します。外部ツール連携に
  `external-tool v0.4`（Steam）と `installer-tool v0.1`（公式インストーラー案内）を追加しました。
- **Avatar Optimizer、ローカル SDK テスト、Recipe v0.6**：任意の `com.anatawa12.avatar-optimizer`
  工程と NDMF クローン指標（`amf-production 0.43.0`、`unity-bridge-v5 0.24.0`）、検証済み下書き入力と旧版移行を備えた
  Recipe 管理および `amf-recipe v0.6`（`0.1.0`）、ローカル Avatar SDK テストビルドとアップロード可否の観察
  （`amf-production-flow v0.1`）を追加しました。作業用 Unity プロジェクトを削除しても完成 Avatar のプレビュー画像を保持します。
- **大規模ライブラリの読取高速化、BOOTH 購入日時、商品情報補完**：読取キャッシュと専用スレッドにより素材スキャン中も
  約 110 ms で応答します。「最近追加」は BOOTH 注文ページの実際の購入日時に従い、所有アイテムの補足情報を取得します
  （`catalog-enrichment v0.1`）。
- **署名付きガイド配信、更新の安全性、五言語 UI の調整**：ローカル同梱フォールバック付きの `guide-content v0.1`
  署名チャンネル、取り下げ済み・非互換コンポーネント更新の安全な扱い、初回案内確認後への自動更新チェック遅延と
  7 日間ログ保持／`Asia/Shanghai` 日次集計（インストール ID なし）の明示、五言語の文言・百科事典・最小ガイドと
  Grid／Aero／Tenshi／Jirai のコントラスト・配置調整を含みます。

## 確認待ちと制限

繁体字中国語を含め、**五言語すべての UI 翻訳は母語話者による確認前**です。自動チェックは言語確認を代替しません。

ビルドツールにはリポジトリ内パターン向けの [minimatch サービス拒否に関する通告](https://github.com/advisories/GHSA-g3hv-75wg-m249)
が残り（実行時依存には含まれません）、PDF フォント処理には[保守終了通知](https://rustsec.org/advisories/RUSTSEC-2026-0192.html)
のある `ttf-parser` 0.25.1 を引き続き使用します（具体的な脆弱性の指摘はなく、置換は今後の作業です）。

作者のチェックを勝手に省略・合格扱いにはしていません。以下の確認が残っています。

| 作者の確認待ち | 未確認の範囲 |
| --- | --- |
| SDK ログイン、ローカル Avatar SDK テストビルド、実験的 VRChat ログインと Avatar 一覧 | 1.1.0 での実アカウント・実 SDK テスト動作 |
| 実際の Unity ライセンス失敗からの案内・復旧 | 合成チェックだけでは Editor の復旧を証明できません |
| 記録したクリーン Windows VM での 1.1.0 ネイティブ導入・削除（オンライン／オフライン） | 新規導入・アンインストールと実機画面 |
| Steam（`v0.4`）および公式インストーラー（`v0.1`）ツールの未導入からの導入・起動 | 検出・起動の検証だけでは新規導入を確認できません |
| 1.0.0／0.7.0 からの更新、GitHub 遮断時の中国本土ミラー `v0.3` 圧縮更新 | データ保持、ランタイム再利用、ミラー転送の実機確認 |
| F4：ラッパー、個別ファイル、入れ子を含む実ライブラリ | 作者の全ファイルを漏れなく扱えるか |
| F5：P-02 予測および Avatar Optimizer 指標とビルド結果の比較、F6：制作中のタイトルバー | 許容差、最適化指標、リソース表示の実測比較 |
| F7：VRCFury 入りの実衣装 | 実素材での検出 |
| F8：クリーン VM で最小ガイドを実行、初回操作と UI の人による確認 | 独力での完走と使いやすさ |

共有リンクは中国本土の試用サーバーを使用しており、他地域からは到達できない場合があります（失敗時はエラーを表示）。
地域別遅延は HTTP の参考値であり、VRChat の部屋の Ping ではありません。

公開後は引き続き [AMF のコミュニティ確認リスト](../development/freeze-plan.md#4-amf-checks-by-the-community)
（複雑な素材、Poiyomi、Avatar Optimizer、フェイストラッキング、並列ライン、利用条件、Recipe 再構築など）をお試しの上、
ホスト・AMF バージョンと個人情報を除いた結果を [GitHub Issues](https://github.com/VUA-Project/VUA/issues)
へご報告ください。認証情報、注文、購入素材は公開しないでください。
