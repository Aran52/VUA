# v1.0.0 Brave New World — Virtual Unified Assistant

> 상태: 출시 준비 중. 1.0.0 공개나 설치 프로그램 검수 완료를 뜻하지 않음
> 갱신: 2026-10-30
> 언어: awaiting native review(원어민 검토 대기)

다른 언어: [English](v1.0.0.md) · [简体中文](v1.0.0_ZH.md) · [日本語](v1.0.0_JA.md)

작성자는 본체의 첫 안정 버전으로 **v1.0.0 Brave New World**를 선택했습니다. **AMF 0.3.0은
Beta를 유지**하며 새 설치에 포함되고 독립적으로 업데이트됩니다. Brave New World는 헉슬리의 소설
『멋진 신세계』와 Stellaris에서 첫 행성을 개척하는 업적의 이름입니다. 안정 버전이라는 단계와 별개로
아래 검수 대기 항목은 남아 있습니다.

## 설치와 업그레이드

준비 중인 Windows x64 파일은 **VUA-1.0.0-windows-x64-setup.exe**(온라인)와
**VUA-1.0.0-windows-x64-offline.exe**(런타임 포함)입니다. 초안에 파일 이름이 있다고 해서
다운로드가 시작된 것은 아닙니다. 공개 전까지 [공식 다운로드 페이지](https://ph-r.com/vua/downloads/)는
기존 공개 버전을 제공합니다. 이번 준비에서는 서명이나 서버 설정을 바꾸지 않습니다.

0.7.0에서 올릴 때는 제작을 마치고 VUA를 종료한 뒤, 정식 공개된 1.0.0 설치 파일을 실행합니다.
본체와 AMF를 함께 업데이트합니다. AMF 0.3.0에는 본체 1.x가 필요하므로 0.7 본체에 단독 모듈
업데이트로 표시되지 않습니다. 소재, Recipe, 설정, 실행 기록, 모듈 선택의 보존은 깨끗한 VM에서 확인해야 합니다.

## 0.7.0 이후의 변경

- [다섯 언어 최소 안내서](../user-guide/v1.0.0/ko.md)는 설치, 첫 사용, 소재부터 SDK까지를 다루고
  실제 1.0.0 렌더러 캡처를 담았습니다. 깨끗한 VM의 설치 캡처와 작성자 절차 검수는 대기 중입니다.
- 앱과 설치 프로그램의 전체 이름을 **Virtual Unified Assistant**로 변경했습니다.
- 처음에는 시스템 언어로 네 부분의 안내를 보여 줍니다. 확인하면 건너뛸 수 있는 기능 둘러보기가 열리고,
  입문 항목에서는 ‘VRChat이란?’부터 한 페이지에 개념 하나씩 설명합니다. 관련 준비 화면과 백과사전으로 이동할 수 있습니다.
- AMF의 소재, Recipe, 작업장, 출시 화면을 작업대 목록에서 엽니다. 공장 지도와 제작 애니메이션을 제거했습니다.
- 라이브러리 이전에 폴더별 선택, 낱개 파일 묶음, 확인·미할당·제외·읽기 불가 구역, 버전이 있는 이전
  목록을 추가했습니다. 계획 화면을 열기만 해서는 가져오지 않습니다.
- 조립 전에 의상별 크기, 삼각형 수, 머티리얼 슬롯, 텍스처 메모리, PhysBones, 파라미터 비트를
  예측합니다. 추정치이므로 실제 빌드 결과와 비교해야 합니다.
- VRCFury 구성 요소를 감지하면 공식 패키지 안내를 표시합니다. 패키지 자체를 배포하지 않습니다.
- 제목 표시줄은 가장 여유가 적은 자원을 표시합니다. 효과가 없던 ‘완료 항목 표시’를 제거했습니다.
- 승인된 Grid, Aero, Tenshi, Jirai 스타일을 제공합니다.
- 독립 구성 요소 업데이트와 복구, 관련 화면의 이용 조건, 회전 이미지·Recipe 공유, 로컬 소재 입력,
  Unity 라이선스 단계, 연결된 Steam 도구의 MCP 접근도 포함합니다.

## 확인 대기와 제한 사항

번체 중국어를 포함해 **다섯 UI 언어 모두 원어민 검토 전**입니다. 자동 배치·조작 검사는 언어 검토를 대신하지 않습니다.

작성자의 검사를 임의로 생략 또는 통과 처리하지 않았습니다. 준비 시점의 상태입니다.

| 작성자 확인 대기 | 아직 검증되지 않은 부분 |
| --- | --- |
| 이름 변경 후 SDK 로그인, 실험적 VRChat 로그인과 Avatar 목록 | 이 후보 버전의 실제 계정 동작 |
| 실제 Unity 라이선스 오류 후 안내와 복구 | 합성 검사만으로 Editor 복구를 입증할 수 없음 |
| 기록한 깨끗한 Windows VM에서 온라인·오프라인 설치 | 새 설치와 설치 프로그램 캡처 |
| Steam 도구 여섯 개를 미설치부터 설치·실행까지 확인 | 감지·실행 기록은 새 설치 확인을 대신하지 못함 |
| 0.7.0 업그레이드, GitHub 차단 후 AMF 미러 업데이트 | 데이터 보존과 중국 본토 미러 활성화 |
| F4: 감싼 폴더·낱개 파일·중첩 모음을 포함한 실제 라이브러리 | 작성자의 모든 파일이 빠짐없이 기록되는지 |
| F5: P-02 예측과 빌드 결과, F6: 제작 중 제목 표시줄 | 허용 오차와 실제 자원 표시 |
| F7: VRCFury가 들어 있는 실제 의상 | 실제 소재에서의 감지 |
| F8: 깨끗한 VM에서 최소 안내서 수행, 첫 사용·UI의 사람 검토 | 추가 도움 없이 완주 가능한지와 사용성 |

공유 링크는 중국 본토의 시험 서버를 사용합니다. 본토에서는 접속할 수 있지만 다른 지역에서는 안 될 수 있으며,
접속 실패 시 오류를 표시합니다. 이번 준비는 서버를 배포하거나 옮기지 않습니다. 지역 지연은 HTTP 참고값으로,
VRChat 방의 Ping이 아닙니다.

공개 뒤에는 [AMF 커뮤니티 검사 목록](../development/freeze-plan.md#4-amf-checks-by-the-community)에 따라 복잡한
소재, Poiyomi, 얼굴 추적, 병렬 제작, 이용 조건, Recipe 재현 등을 확인해 주세요. 이 검사는 동결을 막지 않습니다.
[GitHub 이슈](https://github.com/VUA-Project/VUA/issues)에 본체·AMF 버전, 시나리오, 개인정보를 뺀 결과를
남겨 주세요. 인증 정보, 주문 내역, 유료 소재 파일은 로컬에 보관합니다.

## 빌드와 검수

본체 **1.0.0**, AMF **0.3.0 Beta**(본체 **>=1.0.0, <2.0.0** 필요), Electron **44.9.3**입니다.
AMF UI ABI는 **amf-ui/0.1**, application/Bridge는 **0.1**, BDL 쓰기는 **0.11**, 읽기는 **0.1–0.11**입니다.
관련 문서 버전은 amf-production **0.38.0**, unity-bridge-v5 **0.22.0**, ai-tools **0.10.0**,
라이브러리 이전 **0.1.0**, 이용 조건 **0.2.0**, AMF UI runtime/data recovery **0.1**,
Windows distribution **0.1/0.2**입니다. 전체 목록은 선택한 소스 시점의 [REGISTRY](../REGISTRY.md)를 참조합니다.

이 초안에는 공개된 커밋, 태그, 변경 불가 1.0.0 목록이 없습니다. 검증한 후보를 공개할 때 정확한 소스와
산출물 식별 정보를 기록합니다. 안내서 캡처 목록은 실제 렌더러 소스를 따로 기록합니다. CI 결과는 해당 PR에
있습니다. 후보 검사는 N 단계의 완료나 위 실제 실행의 대체 증거가 아닙니다.

동결 중에는 오류 수정, 보안·호환성 업데이트, 언어 검토를 진행합니다. N7의 전체 그림 안내서와
[동결 이후 작업](../development/freeze-plan.md#after-the-freeze)은 대기합니다.
