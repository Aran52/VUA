# v0.7.0 Stone Age——Avatar 工厂（Beta）

版本由作者选定为 **v0.7.0 Stone Age**，VUA 继续处于 Beta。这一版带来第一条真正的 Avatar
制作路径：从素材库里选好 Avatar 和衣服，VUA 在自己的 Unity 工程里把它们装成一个能用的
Avatar，经你确认后上传到 VRChat。

其他语言：[English](v0.7.0.md) · [日本語](v0.7.0_JA.md) · [한국어](v0.7.0_KO.md)

## 下载与安装

从 [GitHub 发布页](https://github.com/VUA-Project/VUA/releases/tag/v0.7.0) 或
[官网下载页](https://ph-r.com/vua/downloads/) 选择 Windows x64 安装包：

- **VUA-0.7.0-windows-x64-setup.exe**：较小的在线安装包，自带 VUA 和 AMF，安装时从可达的镜像
  获取对应版本的运行时。
- **VUA-0.7.0-windows-x64-offline.exe**：同一版本，自带运行时，适合离线或网络不稳定的环境。

从 v0.6.7 升级：先结束手上的工作，退出 VUA，再运行 0.7.0 的安装包。主程序会升到 0.7.0，
AMF 模块升到 **0.2.0**；AMF 0.2.0 需要 0.7 系列的主程序，所以 v0.6.7 里的模块更新不会提供它。
用户档案、素材库、工程、配方和账号资料都会保留。之后 0.7 系列里的 AMF 更新可以在
「设置 → 模块」或「关于」里完成。

安装包暂时还没有 Windows Authenticode 签名；发布清单的 Ed25519 签名用于校验更新来源。
Unity、VRChat SDK、Steam、VRChat 和各个工具都来自各自的官方渠道。

## 本次变化

### Avatar 制作（AMF）

- **从素材间到成品 Avatar。** 选一个 Avatar 和适配它的衣服，VUA 就开一条产线。每条产线有自己
  的 Unity 工作工程，原始素材包保持不动。
- **车间。** 产线依次经过原料、检查、方案、装配和质检几个工位。VUA 会推荐 Avatar 和衣服的
  预制体，并说明理由。衣服用 Modular Avatar 绑定，每件都有一个菜单开关；预览图从正面、侧面、
  背面展示结果。
- **权限模式。** 「改动前询问」（默认）、「自行决定」和「完全交给 VUA」决定产线在没有你确认时
  能走多远；「完全交给 VUA」会先提醒风险。
- **着色器与依赖包。** 素材需要时，lilToon、Poiyomi Toon（按版本线）和 UnlitWF 会从官方源
  安装；需要你自己获取的包会给出官方页面。
- **材质调整。** 把衣服的 lilToon 亮度上下限对齐到 Avatar，让两者在不同世界里一起变亮变暗。
- **修改与恢复。** 已完成的产线可以换衣服、换 Avatar 底座、删除；Unity 工作可以停止、继续；
  步骤中断后可以恢复。每次改动都留恢复点，改动失败会自动恢复。
- **工作队列。** Unity 工作在可见的队列里排队，最多三条产线并行（在车间里设置）。
- **用大白话讲 SDK 这一步。** VUA 运行 VRChat SDK 自己的 Avatar 检查，把结果分成「上传前必须
  修」、提醒和说明，显示性能等级，并能在出厂页直接运行 SDK 的自动修复。上传后 VUA 会重新读取
  检查结果，你在 SDK 面板里做的修复也会体现出来。
- **出厂间。** 60 帧转台相册；在 VUA 里确认内容权利后，通过打开的 Unity Editor 里的 SDK 托管
  上传。每次上传都会记下 VRChat 的 Avatar ID，或 SDK 给出的原因。
- **使用条款。** 素材库的商品抽屉会读取商品的 VN3 条款，按用途给出能不能用，并把作者的特别
  说明放在最前面。出厂间可以按你选的用途，把一条产线的 Avatar 和衣服一起检查。
- **配方。** 把完成的产线存成配方（按内容记录素材、选择和调整），再应用到另一条产线。
- **Unity 与许可证。** Unity 工作开始前 VUA 会先启动 Unity Hub，能识别 Microsoft Store（MSIX）
  版 Hub，并显示许可证状态和下一步该做什么。

### 实验性 VRChat 登录

默认关闭，在「设置 → 实验性」里。VUA 先讲清风险：VRChat 的条款要求玩家自己保管账号凭据，
第三方登录可能导致账号处理。接受之后在 VUA 里登录，按 VRChat 的要求完成两步验证。之后的托管
上传会让 SDK 直接处于登录状态，出厂间也会把上传的 Avatar 和你的 VRChat Avatar 列表对照。会话
和记住的密码按 Windows 用户加密保存。

### 工具与 AI 助手

- **六个 Steam 工具**共用一套连接：VRCFaceTracking、Space Calibrator、OVR Advanced Settings、
  OVR Overlay Translator、OVR Toolkit 和 OyasumiVR——发现、安装交接、启动和状态。
- **本地 MCP 连接。** 外部 AI 助手可以读取 VUA 的事实并发起操作请求，每个请求都由你在 VUA 里
  批准。返回结果精简，产线的完整事实作为 MCP Resource 提供，错误会说明能不能安全重试；
  `vua_status` 会给出确切的构建版本。

### 界面与语言

- 新增界面语言中文（繁體），待母语审校；原来的中文显示为中文（简体）。Windows 设为繁体中文（台湾、香港或澳门）时，VUA 以繁体打开。
- 提示统一分级：悬停提示、自动消失的轻提示（如“已复制”）、需要处理时的顶部提示条、按钮旁的气泡确认，删除产线这类决定才用对话框。
- 页面和提示更简洁：日常操作不再附带解释，先说结果；排队中的工作显示前方任务数。

### 安全

运行时升级到 Electron 44.9.3，Provider 使用 rustls-webpki 0.103.16 与 webpki-root-certs 1.0.10。
两者都拒绝经由 eMudhra 泄露私钥的中间 CA 签发的 HTTPS 证书（CVE-2026-111943），Electron 同时带来
Chromium 与 V8 的安全回补。安装器、运行时和 Provider 随本版一起更新。

### 其他改进

- 游玩网络卡片对每个地区用三个连接测量，取最快的响应，多次测试得出的最近地区一致。
- 下载进行中任务行保持原位；制作记录在「设置」里；有任务时退出 VUA 会先询问。

## 已验证与待验证

作者机器上的真实运行（2026-10-16 至 10-19）：

- 一个带衣服的 Avatar（Meiyun 加 T 恤短裤）完成准备和装配，lilToon 显示正确，经 SDK 构建后
  通过托管上传以私有方式上传了两次。
- 缺少着色器的材质从官方源装上了 lilToon。
- Unity Hub 未运行时，VUA 启动了它，Unity 拿到了许可证。
- 外部 AI 助手完成了排队、取消、停止与继续、换原料、删除产线和上传，每个请求都由作者批准。

待作者核对：用真实账号的实验性登录；Poiyomi Toon；暗处世界里的亮度对齐；两条产线并行；
更换产线的 Avatar 底座；真实商品的 VN3 条款；多个网络下的地区延迟。

引擎里已经做好、车间界面将在后续版本提供的：产线的版本历史（可恢复最近 50 个状态）、保存的
衣服微调，以及面部捕捉附加包。

这一版不是干净机器、PICO USB/Wi-Fi、复杂素材或四语言的人工验收。地区延迟仍是到各地区参考
源的 HTTP 时延，不是 VRChat 房间的 Ping。
