# v0.6.7 Ibis — 安装版与 AMF 独立更新（Beta）

版本由作者明确指定为 **v0.6.7**，继续处于 Beta。发布不代表 N1、N5、N7 或全部真机验收完成。

## 下载与安装

从 [GitHub Release](https://github.com/VUA-Project/VUA/releases/tag/v0.6.7) 选择 Windows x64 安装包：

- **VUA-0.6.7-windows-x64-setup.exe**：较小的在线安装包，自带 VUA 和 AMF，安装时自动从可达镜像获取完整运行时。
- **VUA-0.6.7-windows-x64-offline.exe**：包含同一版本运行时，适合离线安装或网络不稳定的环境。

安装默认只影响当前 Windows 用户，不需要源码、Node、pnpm 或 Rust。运行时来源包括 npmMirror、华为云和 Electron 官方 GitHub；安装器测试具体文件的可达性，校验同一版本和 SHA-256 后使用。已有完整运行时可以复用。

安装器仍未取得 Windows Authenticode 签名；发布清单的 Ed25519 签名用于校验更新来源，两者用途不同。Steam、SteamVR、VRChat、PICO Connect、Unity 和面捕工具由各自的官方来源提供，不包含在 VUA 安装包内。

## 本次变化

- **安装与更新**：改用 NSIS，提供在线与离线安装；升级和修复保留独立的用户档案。AMF 的界面、资源和后台程序现在作为完整独立模块交付，初始模块版本为 **0.1.0**。在设置 → 模块或关于检查和下载更新，完成当前任务后重启应用。更新按文件复用未变化内容，来源不支持分段下载时显示完整包回退；不重复获取兼容的运行时。
- **更新恢复**：中断后明确继续下载，不自动重放；保留上一份兼容版本供恢复。素材、项目、配方、账号资料以及原先的 AMF 开关选择会保留。卸载默认保留用户档案。
- **BOOTH 与素材库**：修复内嵌登录后同步状态交接、商品图片与分类处理；完善原生分类筛选、批量文件管理、下载进度、卡片角标、商品页面/文件夹入口和适配筛选。保留本地单品导入与资料库迁移预览。
- **列表与交互**：列表按标题、商店、变体、来源分栏，支持列宽调整；来源显示云端、下载中、暂停、已下载、本地导入或错误。修复导入下拉菜单被侧栏遮挡，以及繁忙 Windows 下盘符发现依赖 PowerShell 冷启动的问题。

原有的情景首页、入门引导、游玩/工具/改模、游戏内助手、素材浏览多标签、知识百科、矩阵背景、毛玻璃和资源节约模式继续保留。AMF 新用户默认启用，已有停用选择继续生效。

## 验证边界与已知事项

已用隔离档案验证当前 Windows 上的在线/离线安装、真实 Provider 和独立 AMF 界面启动、运行时复用、卸载保留档案，以及同一宿主上的两个兼容模块版本与回退。自动化检查覆盖签名/校验/路径拒绝、只获取变化文件、完整包回退、取消/继续和繁忙任务拦截。

这不是干净 Windows、真实 PICO USB/Wi-Fi、复杂 Avatar 素材或作者参与的四语言人工验收。原先这些缺口仍保留；区域延迟仍是地理参考目标的 HTTP 时延，不能当作实际 VRChat/Photon 房间 Ping。

本次先发布 GitHub。PH-R.COM 等作者提供部署方式；内部 AMF 更新源暂时仍需要访问 GitHub。在线安装的运行时获取已有中国大陆镜像替代，离线包无需访问更新源即可安装。
