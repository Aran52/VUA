作者已选择 **v1.0.0 Brave New World** 作为本体的首个稳定版。**AMF 0.3.0 保持
Beta**，新安装默认随包启用，之后独立更新。Brave New World 指赫胥黎的小说《美丽新世界》，
也指《群星》中殖民第一颗行星的成就。稳定版是本体的生命周期阶段，下面的验收限制仍然适用。

## 安装与升级

Windows x64 安装包为 **VUA-1.0.0-windows-x64-setup.exe**（在线）和
**VUA-1.0.0-windows-x64-offline.exe**（含运行时），从
[v1.0.0 GitHub 发布页](https://github.com/VUA-Project/VUA/releases/tag/v1.0.0)下载已发布产物。
[官网镜像](https://ph-r.com/vua/downloads/)会标明当前提供的版本。安装包没有 Windows Authenticode 签名，首次运行时 Windows 可能提示风险；发布清单的 Ed25519 签名用于校验更新来源。

从 0.7.0 升级时，先完成制作并退出 VUA，再运行正式发布的 1.0.0 安装器。本体和 AMF 一起升级：
AMF 0.3.0 需要 1.x 本体，0.7 本体不会单独收到该模块更新。升级后素材、Recipe、设置、运行历史
和模块选择是否完整保留，仍需在干净虚拟机上验证。

## 相比 0.7.0 的变化

- ZIP 读取使用 `zip` 9.0.5 并核对本地文件头与中央目录；VN3 PDF 使用
  `pdf-extract` 0.12.1、`lopdf` 0.42.0 拒绝过深嵌套，同时更新 HTTP 依赖和 Vite/Vitest 安全修复。
- 工具详情使用与游玩页相同的展开动画；操作按钮默认显示符号，悬停 1.2 秒后显示文字。
  检查中显示加载圆圈，四款皮肤的游玩卡片对齐。
- 改模复用已验证的环境清单，需要时手动刷新。空的 `fit` 占位数据不再导致装配失败，
  不支持的非空字段仍会被拒绝。
- VN3 刷新读取已记录的条款链接，也可按请求采集商品说明；缺少证据的条款仍显示未知。
  MCP 确认请求支持逐条或全部清除，应用、启动器与安装器使用 VUA 图标。
- [五语言最小指南](../user-guide/v1.0.0/zh-CN.md)覆盖安装、首次使用和素材到 SDK，
  配有真实 1.0.0 渲染器截图。干净虚拟机上的安装器截图和作者通读验收仍待完成。
- 程序与安装器的全名改为 **Virtual Unified Assistant**。
- 首次启动跟随系统语言，显示四段首次使用说明。「知道了」进入可跳过的功能导览；
  入门入口从「什么是 VRChat」开始，每页介绍一个概念，可进入对应准备页面或百科解释。
- AMF 使用素材、Recipe、车间、出厂的工位列表，移除底图和制作动画。
- 素材库迁移支持逐目录选择、散文件分组，分别显示已确认、未分配、已排除和不可读区域，
  并使用带版本的迁移清单。打开规划页不会导入。
- 装配前逐套显示体积、三角面数、材质槽、纹理显存、PhysBones 和参数位预测。
  这些是估计值，使用前仍需与实际构建结果核对。
- 导入时识别 VRCFury 组件，显示官方包引导；VRCFury 由玩家按引导取得，不随包分发。
- 标题栏显示最吃紧的资源；移除没有效果的「显示已完成」设置。
- 提供已批准的 Grid、Aero、Tenshi、Jirai 四种样式。
- 还包含已合并的组件独立更新与恢复、上下文条款、转台与 Recipe 分享、本地素材入口、
  Unity 许可证步骤，以及通过 MCP 访问已连接的 Steam 工具。

## 待检查事项与限制

它处理仓库内固定的构建模式，不在生产依赖图中；兼容的上游构建工具更新仍待完成，请勿用不受信任的模式构建。

## 构建与验收

本体 **1.0.0**；AMF **0.3.0 Beta**，需要本体 **>=1.0.0, <2.0.0**；Electron **44.9.3**。
AMF UI ABI 保持 **amf-ui/0.1**，应用与 Bridge 兼容版本 **0.1**；BDL 写入 **0.11**、
读取 **0.1–0.11**。相关文档版本：amf-production **0.39.0**、unity-bridge-v5 **0.22.0**、
ai-tools **0.11.0**、素材迁移 **0.1.0**、条款 **0.3.0**、AMF UI 运行时与数据恢复 **0.1**、
Windows 分发 **0.1/0.2**。完整矩阵见选定源码版本的 [REGISTRY](../REGISTRY.md)。

发行源码由不可变的 [v1.0.0 标签](https://github.com/VUA-Project/VUA/tree/v1.0.0)确定。
发布页的 `release-manifest.json` 记录确切源码提交，`vua-release.json` 绑定签名载荷清单，
`SHA256SUMS.txt` 记录公开文件校验值。指南截图清单另行记录实际渲染器源码。
CI 结果见对应 PR。发布不关闭 N 阶段，也不替代上述实际运行。

冻结后允许修复、安全与兼容更新、语言审校；完整 N7 图解指南及其他
[冻结后工作](../development/freeze-plan.md#after-the-freeze)继续等待。
