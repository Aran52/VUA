Other editions: [简体中文](v1.1.0_ZH.md) · [日本語](v1.1.0_JA.md) · [한국어](v1.1.0_KO.md)

The author selected **v1.1.0 Getting on Track** for the next stable host release, paired with
**AMF 0.4.0 Beta** (`host >=1.1.0, <2.0.0`). Getting on Track names the *Factorio* achievement
for building a first locomotive. AMF remains Beta, ships enabled for new installations and
continues to update independently when host compatibility permits. Stable describes the host
lifecycle; the pending checks and limits below still apply.

## Installation and upgrade

The prepared Windows x64 installer names are **VUA-1.1.0-windows-x64-setup.exe** (online) and
**VUA-1.1.0-windows-x64-offline.exe** (runtime included). These are expected asset names, not
available downloads until publication. Published downloads remain at
[v1.0.0](https://github.com/VUA-Project/VUA/releases/tag/v1.0.0) and the
[official mirror](https://ph-r.com/vua/downloads/) until promotion. Installers remain unsigned
with Windows Authenticode, so Windows may warn before the first run; the release manifest's
Ed25519 signature verifies the update source.

To upgrade from 1.0.0 or 0.7.0, finish active work, exit VUA (including the system tray icon)
and run the matching 1.1.0 installer once published. It updates the host and AMF together while
reusing a matching verified Electron runtime: AMF 0.4.0 requires host `>=1.1.0, <2.0.0` because
it calls the 1.1.0 host's expanded production, local SDK test, tool-connection and enrichment
surfaces, so a 1.0.0 host is not offered 0.4.0 as a standalone module update. Existing
`%APPDATA%\VUA` application data is preserved; clean-VM upgrade verification remains pending.

## Changes since 1.0.0

- **Modern native Windows installer and uninstaller**: Replaces the multi-step NSIS wizard with
  a single Per-Monitor DPI v2 native setup and uninstall card. It follows system dark/light
  appearance, resolves Windows preferred UI languages (`en`, `zh-CN`, `zh-TW`, `ja`, `ko`) in
  preference order, supports in-place retry when VUA is still running or a download fails,
  launches VUA automatically on completion, and preserves `/S`, `/ISOLATED` and `/D=` flags.
- **Faster startup, smaller disk footprint and compressed updates**: Uses a lightweight static
  boot splash, starts Main and the host Provider in parallel, defers AMF process launch until
  after initial window settlement, hardlinks `VUA.Runtime.exe` to the verified Electron binary,
  hashes files in parallel with launcher-to-bootstrap handoff, trims bundled license notices to
  runtime components, and adds signed `windows-distribution v0.3` zstd component packs. Installed
  size drops roughly in half (about 450 MiB vs 875 MiB in 1.0.0).
- **Scenario-first Launch and external tool connections**: Launch (`scenario-environment v0.2`)
  asks what and how you play across 3 social platforms and 15 setup/device entries (desktop
  screen, SteamVR PC VR, PICO streaming and standalone headset store play) and composes step
  lists for the chosen setup. Tool connections add `external-tool v0.4` Steam entries and
  `installer-tool v0.1` official-installer handoffs.
- **Avatar Optimizer, local SDK testing and Recipe v0.6**: Adds an opt-in
  `com.anatawa12.avatar-optimizer` step with NDMF clone metrics (`amf-production 0.43.0`,
  `unity-bridge-v5 0.24.0`), Recipe management with verified draft prefill, legacy migration and
  `amf-recipe v0.6` (`0.1.0`), plus local Avatar SDK test builds and upload-eligibility
  observations (`amf-production-flow v0.1`). Finished Avatars keep their preview image even
  after their working Unity project is removed.
- **Library speed, BOOTH purchase timestamps and catalog enrichment**: Read caching and
  dedicated reader threads keep large libraries responsive (around 110 ms reads) while material
  scans run; “Recently added” follows actual purchase timestamps from BOOTH order pages, and
  owned BOOTH items gain bounded product observations (`catalog-enrichment v0.1`).
- **Signed guide channel, update safety and five-language UI polish**: Adds the signed
  `guide-content v0.1` channel with bundled fallback and source monitoring, handles withdrawn or
  incompatible component updates safely, defers the first automatic update check until after the
  first-use notice with explicit 7-day log / `Asia/Shanghai` aggregate count disclosure (no
  installation ID), shortens the window and installer display name to `VUA`, and polishes copy,
  encyclopedia entries, minimal guides and theme contrast across Grid, Aero, Tenshi and Jirai.

## Pending checks and known limits

All five UI translations **await native-speaker review**, including Traditional Chinese.
Automated layout and interaction checks do not provide that review.

The build toolchain retains the [minimatch glob denial-of-service advisory](https://github.com/advisories/GHSA-g3hv-75wg-m249)
for repository-controlled build patterns (absent from the production runtime graph; do not build
with untrusted patterns). The PDF font adapter retains `ttf-parser` 0.25.1, which carries an
[upstream unmaintained notice](https://rustsec.org/advisories/RUSTSEC-2026-0192.html) without naming
a specific vulnerability; replacing that adapter remains follow-up work.

No author check is silently marked skipped or passed. These checks remain pending:
