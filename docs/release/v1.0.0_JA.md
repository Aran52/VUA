作者はホスト初の安定版として **v1.0.0 Brave New World** を選びました。**AMF 0.3.0 は
Beta を継続**し、新規インストールに同梱され、個別に更新されます。Brave New World は
ハクスリーの小説『すばらしい新世界』と、Stellaris で最初の惑星に入植する実績の名称です。
安定版という段階でも、以下の未確認事項は残ります。

## インストールと更新

準備中の Windows x64 ファイルは **VUA-1.0.0-windows-x64-setup.exe**（オンライン）と
**VUA-1.0.0-windows-x64-offline.exe**（ランタイム同梱）です。この草稿のファイル名は
ダウンロード開始を意味しません。[公式ダウンロードページ](https://ph-r.com/vua/downloads/)は
公開まで既存の公開版を提供します。署名やサーバー設定は変更していません。

0.7.0 からは制作を終えて VUA を終了し、公開された 1.0.0 インストーラーを実行します。
ホストと AMF を一緒に更新します。AMF 0.3.0 はホスト 1.x が必要なため、0.7 には単体更新として
提示されません。素材、Recipe、設定、実行履歴、モジュールの選択が保たれるかはクリーン VM での確認待ちです。

## 0.7.0 からの変更

- [五言語の最小ガイド](../user-guide/v1.0.0/ja.md)は導入、初回操作、素材から SDK までを扱い、
  実際の 1.0.0 レンダラー画像を掲載します。クリーン VM の導入画像と作者の手順確認は未完了です。
- アプリとインストーラーの正式名を **Virtual Unified Assistant** に変更。
- 初回はシステムの言語で四つの説明を表示します。「了解」からスキップ可能な機能ツアーへ、
  初心者向けの入口から「VRChat とは」へ進みます。一ページに一概念を説明し、対応する準備画面や百科事典へ移動できます。
- AMF は素材、Recipe、ワークショップ、リリースの一覧から開きます。工場マップと制作アニメーションを削除。
- ライブラリ移行にフォルダー単位の選択、個別ファイルのグループ、確認済み・未割当・除外・読取不可の区分、
  バージョン付き移行マニフェストを追加。開いただけではインポートしません。
- 組み立て前に衣装ごとのサイズ、三角形数、マテリアルスロット、テクスチャメモリ、PhysBones、
  パラメータビットを予測します。推定値なので実際のビルド結果との照合が必要です。
- VRCFury コンポーネントを認識し、公式パッケージの案内を表示します。パッケージ自体は同梱しません。
- タイトルバーに最も余裕の少ないリソースを表示。効果のない「完了済みを表示」を削除。
- 承認済みの Grid、Aero、Tenshi、Jirai を提供。
- 個別のコンポーネント更新と復旧、関連箇所での利用条件、ターンテーブルと Recipe の共有、
  ローカル素材の入口、Unity ライセンス手順、接続済み Steam ツールの MCP 操作も含みます。

## 確認待ちと制限

繁体字中国語を含め、**五言語すべての UI 翻訳は母語話者による確認前**です。
自動レイアウト・操作チェックは言語の確認を代替しません。

作者のチェックを勝手に省略済み・合格にはしていません。準備時点では次が未確認です。

| 作者の確認待ち | 未確認の範囲 |
| --- | --- |
| 名称変更後の SDK ログイン、実験的 VRChat ログインと Avatar 一覧 | この候補版での実アカウント動作 |
| 実際の Unity ライセンス失敗からの案内・復旧 | 合成チェックだけでは Editor の復旧を証明できません |
| 記録したクリーン Windows VM でオンライン・オフライン両方のインストール | 新規導入とインストーラー画像 |
| 六つの Steam ツールを未導入からインストール・起動 | 検出・起動のみでは新規導入を確認できません |
| 0.7.0 からの更新、GitHub を遮断した AMF ミラー更新 | データ保持と中国本土ミラーでの有効化 |
| F4：ラッパー、個別ファイル、入れ子を含む実ライブラリ | 作者の全ファイルを漏れなく扱えるか |
| F5：P-02 の予測とビルド結果、F6：制作中のタイトルバー | 許容差と実際のリソース表示 |
| F7：VRCFury 入りの実衣装 | 実素材での検出 |
| F8：クリーン VM で最小ガイドを実行、初回操作と UI の人による確認 | 他の助けなしの手順と使いやすさ |

共有リンクは中国本土の試用サーバーを使います。本土では到達可能ですが、他地域では到達できない可能性があり、
失敗時はエラーを表示します。この準備ではサーバーを展開・移転しません。地域別遅延は HTTP の参考値で、
VRChat の部屋の Ping ではありません。

公開後は [AMF のコミュニティ確認リスト](../development/freeze-plan.md#4-amf-checks-by-the-community)に沿って、
複雑な素材、Poiyomi、フェイストラッキング、並列ライン、利用条件、Recipe 再構築などをお試しください。
これらは凍結を阻止しません。[GitHub Issues](https://github.com/VUA-Project/VUA/issues)へホスト・AMF の版、
手順、個人情報を除いた結果を報告してください。認証情報、注文、購入素材は公開しないでください。
