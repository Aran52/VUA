# v1.0.0 Brave New World — Virtual Unified Assistant

Other editions: [简体中文](v1.0.0_ZH.md) · [日本語](v1.0.0_JA.md) · [한국어](v1.0.0_KO.md)

The author selected **v1.0.0 Brave New World** as the first stable host release. **AMF 0.3.0
remains Beta**, is included for new installations and updates independently. Brave New World
names Aldous Huxley's novel and the Stellaris achievement for colonizing the first planet.
Stable describes the host lifecycle; the acceptance limits below still apply.

## Installation and upgrade

The Windows x64 installers are **VUA-1.0.0-windows-x64-setup.exe** (online) and
**VUA-1.0.0-windows-x64-offline.exe** (runtime included). Download the published assets from the
[v1.0.0 GitHub release](https://github.com/VUA-Project/VUA/releases/tag/v1.0.0).
The [official mirror](https://ph-r.com/vua/downloads/) identifies the version it currently serves.
The installers are not
Authenticode-signed, so Windows may warn before the first run; the release manifest's Ed25519
signature verifies the update source.

To upgrade from 0.7.0, finish production, exit VUA and run the matching 1.0.0 installer when it
is published. It updates the host and AMF together: AMF 0.3.0 needs host 1.x and is not offered
to a 0.7 host as a standalone module update. Preserving materials, Recipes, settings, history
and saved module choices across that upgrade remains a clean-VM acceptance item.

## Changes since 0.7.0

- ZIP reads enforce matching local/central headers with `zip` 9.0.5. VN3 PDF extraction uses
  `pdf-extract` 0.12.1 and `lopdf` 0.42.0 to reject excessive nesting. HTTP dependencies and
  the Vite/Vitest toolchain include their selected security fixes.
- The [minimal guide](../user-guide/v1.0.0/README.md) covers installation, first use and
  materials through the SDK in five languages, with actual 1.0.0 renderer captures. The
  clean-VM installer captures and author walkthrough remain pending.
- The full name is **Virtual Unified Assistant** in the app and installer.
- First use follows the system language and opens a four-part notice. “Got it” starts the
  skippable feature tour; the beginner entry explains one concept at a time, starting with
  VRChat, with links to the matching setup page and encyclopedia.
- AMF opens Warehouse, Recipe, Workshop and Release from a plain station list. The unused
  base map and production animation are removed.
- Library migration has directory choices, loose-file groups, confirmed/unassigned/excluded/
  unreadable areas and a versioned manifest. Opening the planner imports nothing.
- Before assembly, each outfit's plan shows size, triangles, material slots, texture memory,
  PhysBones and parameter bits. These are estimates; compare the built result before relying
  on them.
- Intake recognizes VRCFury components and opens the official-package guide. VRCFury is guide
  delivery, not a bundled package.
- The title bar names the tightest resource. The ineffective “Show completed” setting is gone.
- Grid, Aero, Tenshi and Jirai ship as the four approved styles.
- The merged work also includes independent component updates and recovery, contextual terms,
  turntable/Recipe sharing, local material entry, the Unity license step and MCP access to
  connected Steam tools.
- Tool details share the animated Play drawers; action symbols reveal their labels after
  1.2 seconds of hovering. Loading checks use a spinner, and all four themes align the Play cards.
- Creator reuses its verified environment inventory until refresh. Empty observed `fit`
  placeholders no longer fail assembly; populated unsupported fields remain rejected.
- VN3 refresh reads recorded license links and can capture a product description when requested.
  Missing license evidence stays unknown. MCP confirmation requests can be cleared individually
  or together, and the app, launcher and installers use the VUA icon.

## Pending checks and known limits

All five UI translations **await native-speaker review**, including Traditional Chinese.
Automated layout and interaction checks do not provide that review.

The build toolchain retains the [minimatch glob denial-of-service advisory](https://github.com/advisories/GHSA-g3hv-75wg-m249).
It processes repository-controlled build patterns and is absent from the production dependency
graph. A compatible upstream build-tool update remains pending; do not build with untrusted patterns.
The PDF font adapter also retains `ttf-parser` 0.25.1, which has an
[upstream unmaintained notice](https://rustsec.org/advisories/RUSTSEC-2026-0192.html).
Replacing that adapter remains follow-up work; the notice does not identify a specific vulnerability.

No author check is silently marked skipped or passed. These checks remain pending at publication:

The share-link trial server is deployed in mainland China. It is reachable there and may be
unreachable elsewhere; unavailable links show an error. This release does not deploy
or relocate that server. Regional latency remains an HTTP reference, not a VRChat room Ping.

AMF's community checks do not block the freeze. After publication, please exercise the
[community case list](../development/freeze-plan.md#4-amf-checks-by-the-community), including
complex materials, Poiyomi, face tracking, concurrent lines, terms and Recipe reproduction.
Report results through [GitHub issues](https://github.com/VUA-Project/VUA/issues), with host/AMF
versions, the scenario and a sanitized result. Keep credentials, orders and paid material files local.

## Build identity and acceptance

Host **1.0.0**; AMF **0.3.0 Beta**, host range **>=1.0.0, <2.0.0**; Electron **44.9.3**.
The AMF UI ABI remains **amf-ui/0.1**, application/Bridge compatibility **0.1**, and BDL writes
**0.11**, reading **0.1–0.11**. Served documents include amf-production **0.39.0**,
unity-bridge-v5 **0.22.0**, ai-tools **0.11.0**, library migration **0.1.0**, terms **0.3.0**,
AMF UI runtime/data recovery **0.1** and Windows distribution **0.1/0.2**. The complete matrix
is [REGISTRY](../REGISTRY.md) at the selected source revision.

The release source is the immutable [v1.0.0 tag](https://github.com/VUA-Project/VUA/tree/v1.0.0).
The release's `release-manifest.json` records the exact source commit; `vua-release.json` binds
the signed payload inventory and `SHA256SUMS.txt` identifies the public files. The guide's capture
manifest records its actual renderer source separately. CI results belong to the associated
pull requests. Publication does not close an N stage or replace the pending runs.

The freeze permits fixes, security/compatibility work and language review; the complete illustrated
N7 guide and other [deferred work](../development/freeze-plan.md#after-the-freeze) wait.
