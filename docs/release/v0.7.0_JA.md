# v0.7.0 Stone Age — アバター工房（Beta）

> この日本語版は機械支援で作成しました。ネイティブによる確認待ちです。

バージョンは作者が **v0.7.0 Stone Age** に決めました。VUA は引き続き Beta です。今回は初めての
実用的なアバター制作の流れを届けます。ライブラリからアバターと衣装を選ぶと、VUA が専用の Unity
プロジェクトで組み上げ、あなたの確認のあとで VRChat にアップロードします。

ほかの言語：[English](v0.7.0.md) · [简体中文](v0.7.0_ZH.md) · [한국어](v0.7.0_KO.md)

## ダウンロードとインストール

[GitHub リリース](https://github.com/VUA-Project/VUA/releases/tag/v0.7.0) または
[公式ダウンロードページ](https://ph-r.com/vua/downloads/) から Windows x64 のインストーラーを選びます。

- **VUA-0.7.0-windows-x64-setup.exe**：小さなオンラインインストーラー。VUA と AMF を含み、
  インストール時に届くミラーから対応するランタイムを取得します。
- **VUA-0.7.0-windows-x64-offline.exe**：ランタイムを同梱した同じバージョン。オフラインや
  回線が不安定な環境向けです。

v0.6.7 から更新するには、作業を終えて VUA を終了し、0.7.0 のインストーラーを実行します。本体は
0.7.0、AMF モジュールは **0.2.0** になります。AMF 0.2.0 は 0.7 系の本体が必要なため、v0.6.7 の
モジュール更新には表示されません。プロフィール、ライブラリ、プロジェクト、レシピ、アカウント情報は
そのまま残ります。0.7 系での以後の AMF 更新は「設定 → モジュール」または「バージョン情報」から行えます。

インストーラーにはまだ Authenticode 署名がありません。更新元はリリースマニフェストの Ed25519
署名で確認します。Unity、VRChat SDK、Steam、VRChat と各ツールはそれぞれの公式配布元から入手します。

## 新機能

### アバター制作（AMF）

- **素材の部屋から完成アバターへ。** アバターと対応する衣装を選ぶと、VUA が制作ラインを開きます。
  ラインごとに専用の Unity 作業プロジェクトを持ち、元のパッケージには手を加えません。
- **工房。** ラインは素材、検査、プラン、組み立て、品質チェックのステーションを順に進みます。
  VUA はアバターと衣装のプレハブを理由つきで提案します。衣装は Modular Avatar で着せ、それぞれに
  メニューのスイッチが付きます。プレビューで正面・側面・背面から結果を確認できます。
- **権限モード。** 「変更前に確認」（既定）、「自分で判断」、「すべて任せる」で、確認なしにどこまで
  進めるかを決めます。「すべて任せる」は先に注意を表示します。
- **シェーダーと依存パッケージ。** 素材が必要とするとき、lilToon、Poiyomi Toon（バージョン系列
  ごと）、UnlitWF を公式フィードから入れます。自分で入手するパッケージは公式ページを案内します。
- **マテリアルの調整。** 衣装の lilToon の明るさの上限・下限をアバターにそろえ、どのワールドでも
  一緒に明るく・暗くなるようにします。
- **変更と復元。** 完成したラインの衣装やベースアバターの変更、ラインの削除、Unity 作業の停止と
  再開、中断した手順からの復元ができます。変更ごとに復元ポイントを残し、失敗した変更は自動で
  元に戻ります。
- **作業キュー。** Unity 作業は見えるキューで順番を待ちます。最大 3 本のラインを並行できます
  （工房で設定）。
- **SDK の手順をやさしい言葉で。** VRChat SDK 自身のアバターチェックを実行し、「アップロード前に
  直す」「注意」「メモ」に分け、パフォーマンスランクを表示します。SDK の自動修正はリリース画面から
  実行できます。アップロード後にチェックを読み直すので、SDK パネルで直した内容も反映されます。
- **リリースルーム。** 60 フレームのターンテーブルアルバムと、VUA で権利を確認したあと、開いて
  いる Unity Editor の SDK を通した管理付きアップロード。アップロードごとに VRChat のアバター ID か
  SDK の理由を記録します。
- **利用規約。** ライブラリの商品ドロワーで商品の VN3 規約を読み、用途ごとに使えるかを示します。
  作者の特記事項がいちばん上に来ます。リリースルームでは、選んだ用途でラインのアバターと衣装を
  まとめて確認できます。
- **レシピ。** 完成したラインをレシピ（素材の内容、選択、調整）として保存し、別のラインに適用
  できます。
- **Unity とライセンス。** Unity 作業の前に Unity Hub を起動し、Microsoft Store（MSIX）版の Hub も
  認識します。ライセンスの状態と次にやることを表示します。

### 実験的な VRChat ログイン

既定ではオフで、「設定 → 実験的機能」にあります。先にリスクを説明します。VRChat の規約は
認証情報を本人が管理することを求めており、サードパーティのログインはアカウントへの措置に
つながる可能性があります。同意すると VUA 内でログインし、VRChat の二段階認証を行います。その後の
管理付きアップロードでは SDK がログイン済みの状態で始まり、リリースルームはアップロードした
アバターをあなたの VRChat アバター一覧と照合します。セッションと記憶したパスワードは Windows
ユーザーごとに暗号化して保存します。

### ツールと AI エージェント

- **6 つの Steam ツール** が共通の接続を使います：VRCFaceTracking、Space Calibrator、OVR Advanced
  Settings、OVR Overlay Translator、OVR Toolkit、OyasumiVR。検出、インストールの引き継ぎ、起動、
  状態の確認に対応します。
- **ローカル MCP 接続。** 外部の AI エージェントが VUA の情報を読み、操作をリクエストできます。
  リクエストは毎回 VUA であなたが承認します。結果は簡潔で、ラインの全情報は MCP Resource として
  読めます。エラーには再試行してよいかが付き、`vua_status` は正確なビルドを示します。

### そのほかの改善

- プレイ用ネットワークのタイルは地域ごとに 3 本の接続で測り、いちばん速い応答を使います。
  繰り返し測っても最寄りの地域がそろいます。
- ダウンロード中もタスクの行が動きません。制作記録は「設定」にあります。タスク中に終了すると
  確認します。

## 確認済みのことと、確認待ちのこと

作者の環境での実行（2026-10-16〜10-19）：

- 衣装付きのアバター（Meiyun と T シャツ＆ショートパンツ）を準備・組み立てし、lilToon の表示も
  正しく、SDK でビルドして管理付きアップロードで非公開として 2 回アップロードしました。
- シェーダーが足りないマテリアルに、公式フィードから lilToon を入れました。
- Unity Hub が閉じた状態から VUA が起動し、Unity がライセンスを受け取りました。
- 外部 AI エージェントが、キュー投入、取り消し、停止と再開、素材の変更、ラインの削除、アップロードを
  行い、作者がそれぞれ承認しました。

作者の確認待ち：実アカウントでの実験的ログイン、Poiyomi Toon、暗いワールドでの明るさ合わせ、
2 本のライン並行、ベースアバターの変更、実商品の VN3 規約、複数の回線での地域遅延。

エンジンには入っていて、工房の画面は今後のリリースで提供するもの：ラインのバージョン履歴
（直近 50 の状態から復元）、保存した衣装の位置調整、フェイストラッキングのアドオン。

今回はクリーンな環境、PICO の USB/Wi-Fi、複雑な素材、4 言語の人による受け入れ確認ではありません。
地域の遅延は各地域の参照先への HTTP の応答時間で、VRChat のルーム Ping ではありません。
